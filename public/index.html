Process

How I take a project from fuzzy to finished

01

Discover

Stakeholder chats, user interviews and data dives to frame the real problem and define success.

02

Define

Personas, journey maps and a sharp problem statement so everyone agrees on what we're solving.

03

Ideate

Sketches, wireframes and flows. Lots of options, quickly narrowed down with the team.

04

Design

High-fidelity UI, motion and micro-interactions, built on a reusable component system.

05

Test

Usability sessions and A/B checks, then iterate until the numbers and the users agree.

06

Deliver

Annotated specs, tokens and close collaboration with devs so the build matches the design.
